# SkillVerse AI - Database & Prisma ORM Architecture

This directory houses the complete database schema, SQL migrations, and seeding infrastructure for SkillVerse AI.

## Directory Structure

```
prisma/
├── schema.prisma              # Master Prisma schema with PostgreSQL extensions (vector, uuid-ossp)
├── seed.sql                   # Standalone, standard SQL seed (110 trend signals, 104 embedded roles, 17 SDG targets)
├── migrations/
│   ├── 01_vector_schema.sql   # Core pgvector tables (esco_roles, sdg_targets, trend_signals) & match_roles RPC
│   └── 02_cron_jobs.sql       # Automated nightly signal ingestion cron jobs (pg_cron, pg_net)
└── README.md                  # Database documentation
```

## Database Models & Tables

1. **`esco_roles` (`EscoRole`)**
   - 104+ Future-Resilient standardized occupational roles across 10 critical sectors.
   - Includes multilingual titles (`title_ms`, `title_zh`), benchmark `required_skills`, SDG alignments, scenario multipliers, and 5-axis radar requirements.
   - Indexed with an **HNSW vector cosine index** over 1024-dimensional dense vectors generated by `BAAI/bge-m3`.

2. **`trend_signals` (`TrendSignal`)**
   - 110+ Real-time labor market signals categorized into **emerging** ($V_s > 0.15$), **stable** ($-0.15 \le V_s \le 0.15$), and **declining** ($V_s < -0.15$).
   - Full trilingual metadata (`skillName_ms`, `skillName_zh`, `category_ms`, `category_zh`, `citation_ms`, `citation_zh`).

3. **`sdg_targets` (`SdgTarget`)**
   - 17 UN Sustainable Development Goals benchmark target vectors (SDG 1 through SDG 17) with 1024-dimensional dense vectors.

4. **`users` (`User`) & `user_profiles` (`UserProfile`)**
   - User authentication, demographic profiles, skill sets, tools, target careers, and localized preferences.

5. **`assessments` (`Assessment`) & `shared_roadmaps` (`SharedRoadmap`)**
   - Diagnostic assessments, multi-scenario match results, and dynamic 3-phase reskilling roadmaps.

## Commands

- **Generate Prisma Client:**
  ```bash
  npm run db:generate
  ```
- **Push Schema Changes to Supabase:**
  ```bash
  npm run db:push
  ```
- **Seed Datasets (110+ signals & 104+ embedded roles via seed.sql):**
  ```bash
  npm run db:seed
  ```
